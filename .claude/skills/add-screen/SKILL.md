# 新しい画面を追加する手順

> 技術スタックは Expo（React Native）＋ TypeScript ＋ Expo Router。ファイルの置き場所は CLAUDE.md の「フォルダ構成」に従う（子ども用は `app/(child)/`、保護者用は `app/(parent)/`）。

1. **目的を1つに絞る**
   - この画面で子ども（または保護者）が「何を1つする」画面かを一文で書き、ユーザーに確認する
   - 子ども用か保護者用かをはっきりさせる
2. **流れを決める**
   - どの画面から来て、どこへ戻るか。タップの回数は最小にする
   - 取り消せない操作があれば、確認画面と「もとにもどす」を用意する
3. **文言を先に用意する**
   - 文言ファイルに追加し、`/kid-text-check` の項目で点検する
4. **実装する**
   - `.claude/rules/kid-friendly-ui.md` に沿う（タップ範囲、文字サイズ、セーフエリア、アイコンに文字ラベル）
   - スクリーンリーダー用のラベルを付ける
5. **確認する**
   - 小さいスマホ・大きいタブレット・OSの文字サイズ最大で表示が崩れないか
   - オフラインでも困らないか
   - データを保存する画面なら、保存・読み込みのテストを足す
6. **安全チェック**
   - 個人情報・権限・外部通信に関わるなら `/child-safety-review` を実行する
7. **報告する**
   - 作ったもの、確認したこと、確認できなかったことを分けて伝える
