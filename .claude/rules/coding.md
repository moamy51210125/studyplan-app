# コーディング・開発の進め方

## コード
- 変数名・関数名は英語で、意味の分かる名前にする。コメントは日本語でよい
- TypeScript の `any` は使わない。データの形は `src/types/` に型として定義する
- 表示する文言は**1か所（`src/strings/`）にまとめる**。ふりがな対応や学年別の表示に備える
- 端末内保存の処理は `src/storage/` にまとめ、画面から直接保存ライブラリを呼ばない
- アクセシビリティ（ラベル、フォーカスの順番、文字サイズの拡大）を最初から考える
- 「計画の保存・読み込み」「完了状態の記録」「日付の切り替わり」はテストで守る
- 日付・時刻は端末のタイムゾーンで扱い、日付が変わるときの動きに注意する

## 進め方
- 機能を足す前に、子ども目線で「ひとりで使えるか」「迷わないか」を考える
- 新しいパッケージを足すときは、名前・発行元・用途を伝えて確認を取る。広告・解析系のSDKは入れない（[child-privacy.md](child-privacy.md)）
- ファイル削除や大きな変更の前には確認する
- git の初期化・コミット・push は、頼まれたときだけ行う
