# 子どもの安全・プライバシー点検

基準は `.claude/rules/child-privacy.md`。この点検は、そのルールが守られているかを確かめる手順です。

## 手順
1. 今回の変更点（追加・変更したファイル、追加したパッケージ）を一覧にする
2. 下のチェック項目で点検する
3. 結果を `OK / 要対応 / 要確認（ユーザー判断）` に分けて報告する
4. 「要対応」は直し方の案を出し、ユーザーの了承を得てから直す

## チェック項目
- **個人情報**
  - [ ] 新しく集める情報はないか。あれば本当に必要か
  - [ ] 本名・学校名・写真・位置情報などを保存・表示していないか
- **データの流れ**
  - [ ] 端末の外にデータを送るコードがないか（通信ライブラリ、`fetch` など）
  - [ ] ログに個人情報や学習記録を出していないか
- **パッケージ**
  - [ ] 追加したパッケージに広告・解析・トラッキングの機能が含まれていないか
  - [ ] 発行元・用途をユーザーに伝えて確認を取ったか
- **端末の権限**
  - [ ] 新しい権限（カメラ・位置情報・連絡先など）を要求していないか
  - [ ] 通知は保護者がオン・オフできるか
- **導線**
  - [ ] 子ども画面から外部リンク・課金・他人との交流につながらないか
  - [ ] 削除・初期化などは、保護者の確認ステップを通るか
- **秘密情報**
  - [ ] APIキー・トークン・パスワードがコードに直書きされていないか
