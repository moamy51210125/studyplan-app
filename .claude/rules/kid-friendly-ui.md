# 小学生向けスマホUIの原則

## 見た目と操作
- 本文の文字は 16pt 以上、主要ボタンの文字は 18pt 以上を目安にする
- タップできる範囲は **最低 44×44pt（iOS）／ 48×48dp（Android）**。ボタンどうしの間隔も十分に空ける
- 1画面でやることは1つ。操作の手順はできるだけ少なくする
- アイコンには必ず文字ラベルを付ける
- 色だけで意味を伝えない。コントラスト比は WCAG AA 以上にする
- 長押し・ダブルタップ・複雑なスワイプなど、分かりにくい操作を必須にしない

## スマホならではの配慮
- 縦向きを基本にし、タブレットの横向きでも表示が崩れないようにする
- ノッチ・ホームバーの領域（セーフエリア）を避けて配置する
- OSの文字サイズ設定を大きくしても、文字が切れたり重なったりしないようにする
- スクリーンリーダー（VoiceOver / TalkBack）用のラベルを付ける
- オフラインでも基本の機能（計画を見る・チェックする）は使えるようにする

## 安心して使える設計
- **取り消せない操作の前には確認を出す**（例：「ほんとうに けしてもいい？」）。できれば「もとにもどす」も用意する
- できなかった日も責めない。失敗や未達成を目立たせない
- ごほうび（スタンプ・バッジ）は学習のやる気づけにとどめる。ガチャのような要素や、ランキングで他人と比べる仕組みは入れない
- 無限スクロールやしつこい通知など、長く使わせるための仕組みは入れない
