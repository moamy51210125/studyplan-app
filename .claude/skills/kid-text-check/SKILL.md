# 表示テキストの小学生向けチェック

## 手順
1. 対象を決める。指定がなければ、文言ファイルのうち今回追加・変更した部分を対象にする
2. 各文言を下のチェック項目で点検する
3. 結果を表で出す：`場所 | いまの文言 | 問題点 | 書き換え案`
4. ユーザーの了承を得てから文言ファイルを書き換える
5. 書き換えた文言が画面に収まるか（ボタンの幅、OSの文字サイズを大きくした場合）を確認する

## チェック項目
- [ ] 低学年でも読めるか（むずかしい漢字にふりがながある／ひらがなになっている）
- [ ] カタカナ語・専門用語がないか（`.claude/rules/wording.md` の言いかえ表を参照）
- [ ] 1文が短いか（目安：20文字前後まで）
- [ ] 責める言い方、こわがらせる言い方になっていないか
- [ ] エラー文に「次にどうすればいいか」が書いてあるか
- [ ] 呼びかけがやわらかいか（「〜してね」「〜できたね！」）
- [ ] 保護者画面の文言は、子ども向けにしすぎず丁寧な日本語になっているか
- [ ] 文言がコードに直接書かれず、文言ファイルにあるか
