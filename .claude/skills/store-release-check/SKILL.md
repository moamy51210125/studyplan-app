# アプリストア申請前チェック

> **このスキルは確認だけを行います。** ストアへのアップロード・申請・公開は外部への操作なので、必ずユーザーが自分で行うか、明示的な承認を得てから行います。

## 手順
1. `/child-safety-review` をアプリ全体に対して実行する
2. 下の項目を確認し、`OK / 要対応 / 未確認` で報告する
3. ストアのポリシーは変わることがあるため、**最新の公式ポリシーをユーザーに確認してもらう**。内容を推測で断定しない

## 確認項目
- **子ども向け区分**
  - [ ] App Store の「キッズ」カテゴリ、Google Play の「ファミリー」向けポリシーに申請するかどうかを、ユーザーが決めているか
  - [ ] それぞれの最新要件（広告・解析SDKの制限、外部リンクの扱い、保護者ゲートなど）を公式ページで確認したか（要確認）
- **プライバシー**
  - [ ] プライバシーポリシーがあり、内容がアプリの実際の動きと一致しているか
  - [ ] ストアのプライバシー申告（App のプライバシー / データセーフティ）が実際の動きと一致しているか
- **表示・品質**
  - [ ] 対象年齢・説明文・スクリーンショットが実際の画面と一致しているか
  - [ ] 説明文に根拠のない効果（「成績が上がる」など）を書いていないか
  - [ ] 小さいスマホ・タブレット・OSの文字サイズ最大で崩れないか
  - [ ] オフラインで起動して基本の操作ができるか
- **秘密情報**
  - [ ] 署名鍵・証明書・ストアの認証情報をリポジトリに入れていないか
