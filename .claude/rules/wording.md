# 表示することばのルール

- **やさしい日本語**にする。むずかしい漢字には**ふりがな**を付けるか、ひらがなにする
  - 低学年向けの表示はひらがな中心にする
  - 学年に合わせて漢字の量を切り替えられる設計を考える
- カタカナ語・専門用語は使わない

| 使わない | 使う |
|---|---|
| タスク | やること |
| 完了 | できた！ |
| 削除 | けす |
| 保存 | のこす / きろくする |
| 設定 | せってい（保護者画面では「設定」でよい） |
| エラー | うまくいかなかったよ |

- エラーメッセージは責めない言い方にし、次にすることを示す
  - 悪い例：「入力エラー」　良い例：「なまえを いれてね」
- 子どもに呼びかけるときは、やわらかい言い方にする（「〜してね」「〜できたね！」）
- 保護者画面は、ふつうの丁寧な日本語でよい
- 表示する文言はコードに直接書かず、文言ファイルにまとめる（[coding.md](coding.md) を参照）
